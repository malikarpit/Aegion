# Authorized Subprocessors

**Last Updated**: [DATE]

Aegion engages the following third-party entities to process Customer Data:

| Subprocessor | Purpose | Location | Data Categories | DPA Status |
|---|---|---|---|---|
| **Amazon Web Services (AWS)** | Cloud Infrastructure Hosting (Compute, DB, Storage) | US / EU / APAC | All Customer Data | Signed (AWS DPA) |
| **OpenAI / Anthropic** | LLM Inference (Reasoning Engine) | US | User Prompts (Redacted) | Signed (Zero-Retention) |
| **Neo4j Aura** | Graph Database Hosting | US / EU | Knowledge Graph Data | Signed |
| **Auth0 / Okta** | Identity & Access Management | US | User Identity, Emails | Signed |
| **Datadog / Splunk** | Observability & Logging | US | System Logs (No PII) | Signed |
| **Stripe** | Payment Processing | US | Billing Info | Signed |
| **Sentry** | Error Tracking | US | Stack Traces (Sanitized) | Signed |

## Change Notification

Subscribing to this list ensures you receive notifications of any new subprocessors 30 days prior to their authorization to process data.
