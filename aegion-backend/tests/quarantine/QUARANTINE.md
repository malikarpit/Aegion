# Test Quarantine

This directory contains tests that are flaky or broken and have been temporarily disabled to unblock the CI pipeline.

## Policy
1. **Admission**: If a test fails 3 times in a row on `main` without code changes, it may be moved here.
2. **Ownership**: Every file here MUST have an owner assigned in the table below.
3. **Expiry**: Tests must be fixed or deleted within 2 weeks.
