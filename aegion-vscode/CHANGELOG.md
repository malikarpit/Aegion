## [0.1.0] - 2026-02-10

### Added
- **Core Features**
  - Session management with workspace context
  - Proposal creation and approval workflow
  - Tiered governance (T0-T3) support
  - Real-time event streaming via SSE

- **AI Integration**
  - AI Council invocation with structured responses
  - Ghost Text inline suggestions
  - Evidence-backed recommendations

- **Webview Panels**
  - Governance Sidebar with session overview
  - Decision Governance Center
  - Chronos Explorer for history
  - Architecture Timeline panel
  - Sentinel Health dashboard
  - War Room for T3 escalations

- **Collaboration**
  - Workspace participant tracking
  - Decision graph visualization
  - ADR generation and linking

### Technical
- TypeScript + Webpack build pipeline
- Firebase authentication integration
- EventSource polyfill for Node.js compatibility
